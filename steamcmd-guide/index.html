SteamCMD Guide: Official Workshop Downloads

SteamCMD is Valve's official command-line version of the Steam client. It's the most reliable way to download Workshop content in bulk — required for dedicated servers and the only tool that can expand collections automatically.

Setup

  1. Download SteamCMD for your OS from developer.valvesoftware.com.
  2. Extract it to a folder with free space (it self-updates on first run).
  3. Launch it — it updates and drops you at a Steam> prompt.

Core commands

At the Steam> prompt: login anonymous (no account needed for Workshop downloads). Then force_install_dir ./output to set where files land. Then workshop_download_item pulls a single item. Repeat per item, or use a collection-expansion script for whole collections.

When SteamCMD beats a browser downloader

  • Collections with 50+ mods (scriptable, resumable)
  • Dedicated servers that auto-refresh content
  • Items above ~500 MB that may time out in browser tools
  • Scheduled/automated mod updates

FAQ

Is SteamCMD free?

Yes — it's Valve's official tool, no account required for Workshop downloads.

Can SteamCMD download private items?

No — only public items, same as browser tools.
