RimWorld Workshop Downloader

RimWorld has one of the biggest mod scenes on Steam — thousands of mods tagged by supported game version (1.0 through 1.6). This tool lets you preview and download any public RimWorld Workshop mod without opening Steam.

How to download a RimWorld mod

  1. Copy the mod's link from the RimWorld Workshop (steamcommunity.com/app/294100/workshop).
  2. Paste it into the homepage input and press Load.
  3. Check the version tags — the preview shows which RimWorld versions the mod supports (1.4, 1.5, 1.6...).
  4. Click Download ZIP and drop the extracted folder into your RimWorld Mods directory.

Checking mod compatibility

The preview shows the mod's tags, including game versions. Always match the mod's newest supported version with your RimWorld install — loading a 1.4-only mod in 1.6 usually breaks saves. Also read the description for required dependency mods like Harmony or HugsLib; download those first.

Installing the ZIP

Extract the ZIP into RimWorld's Mods folder: on Windows that's usually C:\Program Files (x86)\Steam\steamapps\common\RimWorld\Mods, or wherever your game install lives. The mod appears in the game's mod list on next launch.

FAQ

Does it work for RimWorld 1.6 mods?

Yes — any public Workshop item, regardless of version tag.

Where is the RimWorld Mods folder?

Inside your RimWorld game install, next to the executable. Steam default: steamapps/common/RimWorld/Mods.
