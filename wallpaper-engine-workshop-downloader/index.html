Wallpaper Engine Workshop Downloader

Wallpaper Engine's Workshop is packed with animated and scene wallpapers. If you don't have Steam open — or want a wallpaper file on another device — this tool fetches any public wallpaper's package directly.

How to download a wallpaper

  1. Copy the wallpaper's Workshop URL (steamcommunity.com/app/431960/workshop).
  2. Paste it into the homepage field and press Load.
  3. Preview the image, check file size, then click Download ZIP.
  4. The ZIP contains the wallpaper project files (scene.pkg, project.json, media assets).

Using the files

Place extracted folders into wallpaper_engine/projects/myprojects/ — Wallpaper Engine picks them up as local wallpapers on next launch. You can also open .pkg scene files with Wallpaper Engine's editor.

A note on sizes

Animated wallpapers range from a few MB to several hundred MB for video-heavy scenes. Check the preview size before downloading on mobile data.

FAQ

Do these wallpapers work without Wallpaper Engine installed?

The files are packages for the app — you need Wallpaper Engine (or its editor) to play them.

Can I preview animated wallpapers here?

The preview shows the wallpaper's thumbnail image; the animation plays inside Wallpaper Engine.
